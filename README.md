# Cyberpunk 2077 Theme for Claude Code

Neon red, cyan and yellow on deep black — inspired by the Cyberpunk 2077 UI
and the [Discord Cyberpunk 2077 theme](https://github.com/PatrykBielanin/discord-cyberpunk2077-theme).

| Role | Color |
|---|---|
| Accent / Claude | `#FF003C` |
| Suggestions / Plan mode | `#72EAF8` |
| Permissions / Warnings | `#F3E600` |
| Success | `#47D58B` |
| Text | `#D3D3D3` |

## Install

### As a plugin (recommended)
```
/plugin marketplace add Pigasor/claude-code-cyberpunk2077-theme
/plugin install cyberpunk2077-theme@cyberpunk2077-theme
```
Then run `/theme` and pick **Cyberpunk 2077**.

### Manually
Copy `themes/cyberpunk-2077.json` to `~/.claude/themes/`, then run `/theme`.

> Tip: for the full look, set your terminal font to **Rajdhani** (or a similar
> condensed font) and the background to pure black.
